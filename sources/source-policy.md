# 출처 사용 원칙

이 저장소에서 사용하는 출처의 우선순위와 검증 원칙을 정의합니다.

---

## 출처 우선순위

### 1순위 — 정당 공식 자료
- 정당 공식 홈페이지
- 공식 강령 (당헌·당규 포함)
- 정책자료집
- 공식 보도자료
- 선거 공약집 (정당 직접 발행)

### 2순위 — 중앙선거관리위원회
- [정책·공약마당](https://policy.nec.go.kr/)
- [정당 등록·강령 현황](https://www.nec.go.kr/site/nec/politicalParty/doctrineConstitutionList.do)
- 선거공보 (관보 게재분)

### 3순위 — 국회 공개 자료
- [열린국회정보 — 정당·교섭단체 현황](https://open.assembly.go.kr/portal/assm/assmPartyNegotiationPage.do)
- [국회 의안정보시스템](https://likms.assembly.go.kr/)
- 국회 회의록
- 국회도서관 정책자료 (https://ampos.nanet.go.kr/)

### 4순위 — 공신력 있는 언론 보도
- 기자회견·인터뷰 원문
- 언론사 스트레이트 뉴스
- 팩트체크 기사

### 5순위 — 학술·연구 자료
- 국회입법조사처 (https://www.nars.go.kr/)
- 국책 연구기관 보고서
- 학술 논문 (정치학, 사회학)

## 사용 금지 또는 주의 출처

| 유형 | 처리 방법 |
|------|----------|
| 커뮤니티 게시물 | 사용 금지 |
| 편집 불명확한 위키 | 참고용으로만 사용, 1~3순위로 교차 검증 필수 |
| 짧은 SNS 캡처 | 사용 금지 (공식 계정의 전문(全文)은 예외) |
| 출처 없는 요약글 | 사용 금지 |
| 의견 칼럼·논평 | 정당 입장이 아닌 필자 의견임을 명시 |

> **예외**: 논란의 존재 자체를 확인할 때는 보조자료로만 사용 가능합니다.

---

## 정보 신뢰도 등급

모든 `metadata.yaml`의 `confidence` 항목에서 사용하는 등급입니다.

| 등급 | 기준 |
|------|------|
| `high` | 1순위 또는 2순위 출처에서 직접 확인된 사항 |
| `medium` | 3순위~4순위 복수 출처에서 교차 확인된 사항 |
| `low` | 단일 출처이거나 추정 요소 포함 |

---

## 시간 민감 정보 처리

다음 항목은 변동 가능성이 높으므로 반드시 `last_checked` 날짜를 함께 기록합니다.

- 정당명 (개명, 합당, 분당 가능)
- 당대표·원내대표 (전당대회, 당내 선거로 교체)
- 의석수 (보궐선거, 탈당, 입당으로 변동)
- 교섭단체 여부 (의석수 변동에 따라 변경)
- 정책 입장 (선거 시기, 정치 상황 변화에 따라 변경)

**업데이트 권장 주기**:
- 전당대회 후: 지도부 정보 즉시 업데이트
- 국회의원 선거 후: 의석수 즉시 업데이트
- 대통령 선거 후: 여야 관계 및 정책 기조 업데이트
